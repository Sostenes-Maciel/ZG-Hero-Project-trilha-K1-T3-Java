# Skill de Code Review

## Objetivo

Revisar código buscando qualidade, segurança e alinhamento com os requisitos definidos na especificação do projeto.

## Checklist de Revisão

1. **Legibilidade e clareza:** verificar nomes de variáveis, organização, estrutura dos métodos, duplicação e facilidade de manutenção.
2. **Aderência à spec:** confirmar se o código implementa o que a especificação pede e nada além do escopo aprovado.
3. **Casos de borda sem teste:** identificar cenários extremos, entradas inválidas, falhas de integração e comportamentos limítrofes ainda não cobertos.

## Formato de Saída

Produzir um relatório estruturado com:

- severidade e localização de cada apontamento;
- descrição objetiva do problema ou risco;
- relação com a especificação ou checklist;
- sugestão de correção;
- indicação do que foi corrigido durante a revisão;
- declaração explícita quando não houver apontamentos relevantes.
